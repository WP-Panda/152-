# WP Panda Vault

Self-hosted система приватных обновлений WordPress-продуктов на PHP и WordPress. Серверная и клиентская части выделены в отдельные каталоги верхнего уровня:

- **[`server/`](server/README_RU.md)** — WordPress-плагин издателя: каталог продуктов и релизов, закрытое хранение ZIP, REST API и администрирование лицензий/активаций.
- **[`client/`](client/README_RU.md)** — SDK для встраивания в распространяемый плагин или тему, встроенный экран лицензий и необязательные MU-loaders.

## Возможности

- Индивидуальные ключи на **1, 3 или 5 сайтов** с записью и контролем активаций.
- Плагины и темы обновляются через стандартные механизмы WordPress.
- На сайте клиента SDK автоматически добавляет страницу **Настройки → Panda Updates**, если продукт не использует собственную страницу. Для собственной страницы есть функция `wp_panda_updater_license_field($slug, $type)`.
- Рядом с полем ключа выводится сообщение: **«Лицензия не влияет на работоспособность продукта, а только на получение обновлений»**.
- ZIP-файлы хранятся вне web-root; ссылки на загрузку краткоживущие и подписанные.

Лицензия контролирует только получение обновлений. Продукт продолжает работать без ключа или при недоступности сервера лицензий. Решение не является DRM и не доказывает владение доменом; см. раздел ограничений в руководствах.

## Быстрый старт

1. Установите `server/wp-panda-vault/` на WordPress-сайт издателя и выполните настройки закрытого хранилища.
2. В **Панель → Panda Vault** создайте продукт, опубликуйте ZIP и выпустите индивидуальный ключ с лимитом 1, 3 или 5 сайтов.
3. Добавьте `client/wp-panda-updater.php` в исходный код продукта и зарегистрируйте SDK. Первую версию установите клиентам обычным способом.
4. Клиентский администратор активирует выданный ключ в Panda Updates либо в блоке лицензии на странице настроек продукта.
5. Загружайте последующие версии в Vault; клиенты увидят их в штатной панели обновлений WordPress.

Подробные инструкции, примеры интеграции, безопасность, обслуживание и устранение неполадок: [руководство сервера](server/README_RU.md) и [руководство клиента](client/README_RU.md).
