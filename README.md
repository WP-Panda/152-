# WP Panda Vault (PHP + WordPress)

Полноценный WordPress-плагин для управления приватными релизами своих плагинов и тем. Серверная часть написана на PHP и работает внутри WordPress; интерфейс администрирования находится в **Панель WordPress → Panda Vault**. Отдельный Node.js-сервер и сторонняя SaaS-панель не нужны.

Файлы архивов хранятся в отдельном каталоге за пределами `ABSPATH` и web-root. WordPress отдаёт ZIP только по краткоживущей HMAC-подписанной ссылке, после проверки целостности SHA-256. Встроенный клиент `wordpress/wp-panda-updater.php` подключает продукты к стандартной системе обновлений WordPress для плагинов и тем.

**Полное описание и руководство администратора:** [docs/USER_GUIDE_RU.md](docs/USER_GUIDE_RU.md).

## Компоненты

- `wordpress/wp-panda-vault/` — серверный плагин: таблицы продуктов/релизов, панель администратора, безопасная загрузка ZIP и REST API.
- `wordpress/wp-panda-updater.php` — клиентский SDK, который встраивается в поставляемый плагин или тему.

## Быстрый старт

1. Установите `wordpress/wp-panda-vault/` как обычный плагин WordPress (упакуйте каталог в ZIP или скопируйте его в `wp-content/plugins/`).
2. Перед активацией настройте закрытый каталог в `wp-config.php`, если каталог по умолчанию не подходит:
   ```php
   define('WP_PANDA_VAULT_STORAGE_DIR', '/var/lib/wp-panda-vault/site-1');
   define('WP_PANDA_VAULT_SECRET', 'сюда-случайную-строку-минимум-32-символа');
   ```
   Владелец PHP-процесса должен иметь право создать/записывать файлы. Каталог обязан находиться **вне web-root и `ABSPATH`**.
3. Активируйте плагин. Откройте **Панель → Panda Vault**, создайте продукт, сохраните его ключ и загрузите первый ZIP-релиз.
4. Скопируйте `wordpress/wp-panda-updater.php` в ваш пакет, добавьте клиентскую конфигурацию и задайте ключ в `wp-config.php` на авторизованных WordPress-сайтах.
5. Первую сборку установите вручную. Последующие версии появятся в штатной панели **Консоль → Обновления**.

Системные требования: WordPress 6.0+, PHP 7.4+, PHP ZipArchive, TLS/HTTPS для публичного сервера. Руководство содержит инструкции по сборке архива, Nginx/HTTPS, API, резервным копиям, безопасности и диагностике.
