# WP Panda Vault — руководства

Документация разделена по назначению и компонентам:

- **[Сервер издателя](../server/README_RU.md)** — установка WP-плагина Vault, приватное хранилище, публикация ZIP, выпуск индивидуальных лицензий, контроль активаций, REST API, безопасность, резервные копии и диагностика.
- **[Клиент и интеграция SDK](../client/README_RU.md)** — подключение к плагину/теме, автоматическая страница лицензий, интеграция в существующие настройки через `wp_panda_updater_license_field()`, MU-loaders, активация и диагностика.

Ключевое правило для пользователей продукта: **лицензия не влияет на работоспособность продукта, а только на получение обновлений**.
